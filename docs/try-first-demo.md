# ทางเริ่มทดลองสำหรับคนที่ยังไม่รู้ว่าจะลองอะไร

หน้าแรกแทนพื้นที่แนะนำทั่วไปด้วยตัวเลือกที่บอกทั้งงานและผลที่จะเห็น มีทางเริ่มหลักคือ “ลองเปลี่ยนงบรายวัน” และอีกสองทางคือ “ลองตรวจผู้รับก่อนโอน” กับ “ลองปรับเงินสำรอง” แต่ละเรื่องพาไปโฟกัสกล่องแนะนำข้างส่วนที่ใช้งานจริง ปิดคำแนะนำแล้วลองเองต่อได้

## เงื่อนไขการนับว่าลองแล้ว

- งบรายวัน: เปลี่ยนเป็นงบที่ถูกต้องและต่างจากค่าปัจจุบัน ผ่านปุ่มตัวอย่าง พิมพ์เอง เลื่อนแถบ หรือกดงบลัด ตัวเลขเงินเหลือคำนวณด้วยสูตรเดิมและแสดงทันทีในกล่องแนะนำ
- ผู้รับก่อนโอน: เปิดผลตรวจจากเซิร์ฟเวอร์จริงในต้นแบบ ไม่ใช่แค่เปิดหน้าโอน เริ่มด้วยผู้รับสมมติที่ควรตรวจเพิ่มและยอดไม่เกินเงินที่มี รายการที่รอตรวจเดิมจะถูกเปิดกลับโดยไม่สร้างใหม่หรือเริ่มเวลาพักใหม่
- เงินสำรอง: ได้รับผล preview จาก API แล้ว แสดงงบก่อน–หลังทันที ไม่บังคับบันทึกยอดใหม่

ความคืบหน้าเป็นสถานะการเรียนรู้ในหน้าที่เปิดอยู่ ไม่ใช่รายการธุรกรรมหรือข้อมูลถาวร รีเฟรช เปลี่ยนบัญชี หรือรีเซ็ตจะเริ่มการแนะนำใหม่ เลือกเรื่องที่ลองแล้วซ้ำได้ การกดลองไม่รีเซ็ตยอดบัญชี ไม่ออม ไม่ถอน และไม่ยืนยันโอนให้ผู้ใช้

หลังเห็นผลมีปุ่มไปเรื่องที่ยังไม่ได้ลอง เมื่อครบกลับมาดู 3/3 และใช้เมนูตามปกติได้ ส่วนขั้นตอนยืนยันโอนและยืนยันเงินสำรองยังเป็นการตัดสินใจแยกจากการทดลอง

## สีและการตรวจสอบ

ปุ่มลูกศรหน้าสรุปงบเปลี่ยนจากเขียวมะนาวเป็นเขียวอมฟ้าหม่น `#d0e6e2` กับลูกศรเข้ม `#245759` แถบงบ ป้ายแนะนำ และสีส่วนที่เหลือแบ่งใช้ปรับให้กลมกลืนกัน ยังคงสีคอรัล ฟ้า และทองเพื่อแยกหน้าที่

Build และชุดทดสอบ UI 13 ข้อผ่าน ตรวจผ่านเบราว์เซอร์ทั้งสามเส้นทาง การเปิดรายการโอนเดิม โฟกัสในหน้าต่างผลตรวจ ความคืบหน้า 3/3 การแสดงผลทันที และการ preview โดยยอดสำรอง/เงินบัญชีไม่เปลี่ยน ตรวจความกว้าง 320 และ 390 พิกเซลไม่พบการล้นแนวนอน คอนโซลรอบสุดท้ายไม่มี error/warning

ต้องให้ผู้ใช้กลุ่มใหม่ลองโดยไม่บอกตำแหน่งปุ่ม เพื่อวัดว่ารู้สิ่งที่ทำได้ เริ่มทดลองเอง และอธิบายผลได้หรือไม่ การตรวจโดยผู้พัฒนายังไม่พิสูจน์ว่าปัญหาความเข้าใจลดลงแล้ว
