# Tutorial แบบชี้ตำแหน่งบนหน้าจอ

Hero ภาพประกอบเดิม “จัดเงินให้พอใช้ ถึงวันเงินเดือน” กลับมาเป็นจุดหลักของหน้าแรก การ์ดเลือกทดลอง 3 เรื่องและกล่องแนะนำในเนื้อหาถูกแทนด้วย tutorial แบบ spotlight มีลูกศรและกล่องคำอธิบายลอยข้างจุดที่กำลังแนะนำ

## ลำดับ 8 ขั้น

1. ปุ่มเข้าแผนเงินใน Hero — กดปุ่มจริงหรือกดถัดไปได้
2. งบรายวัน — เลือกปุ่มงบจริงแล้วไปอ่านผล หรือกดถัดไปเพื่อดูค่าปัจจุบัน
3. ผลคำนวณงบ — ชี้เงินเหลือก่อนเงินเดือนและสถานะเงินสำรอง
4. ช่องเงินสำรองและปุ่ม preview — ปรับค่าและดูผลได้ แต่การบันทึกยังต้องยืนยันแยก
5. ปุ่มตรวจโอน — เตรียมผู้รับและยอดสมมติ ให้ผู้ใช้กดดูผลเอง ไม่มีการยืนยันโอน ถ้ามีรายการรออยู่เปิดรายการเดิมโดยไม่เริ่มเวลาพักใหม่
6. ผลก่อน–หลังโอน — ชี้ตัวเลขในหน้าต่างตรวจสอบจริง
7. เงินออมที่ถอนได้ — อธิบายการย้ายเงินเดิมกลับมาใช้ ไม่มีการถอนให้
8. การแยกออม — อธิบาย opt-in และส่วนที่พร้อมออม แล้วจบกลับหน้าแรก

ช่วงที่ชี้ผลลัพธ์/อธิบาย แตะจุดที่ชี้หรือกดถัดไปได้ ช่วงที่มีตัวควบคุมจริง กดใช้งานได้ตามปกติ เช่น เลือกงบหรือเปิดผลตรวจ แต่ tutorial ไม่กดบันทึกเงินสำรอง ยืนยันโอน เปิดออม หรือถอนเงินแทนผู้ใช้

มีปุ่มย้อนกลับ ข้าม และ Escape การข้ามไม่ยกเลิกรายการโอนที่รออยู่ หลังดูจบหรือข้ามจะจำเพียงสถานะการแนะนำใน localStorage (`kplus-feature-tour-v1`) เพื่อไม่เปิดซ้ำทุกครั้งที่รีเฟรช ไม่มีการเก็บยอดเงินหรือเลขบัญชีในค่านี้ กด “พาชมวิธีใช้” บน Hero เพื่อเปิดใหม่ได้ หาก browser ปิด storage ยังเปิด/ข้าม/จบได้

## การแสดงผลและคีย์บอร์ด

- วางกล่องด้านข้างเมื่อมีพื้นที่ บนมือถือเลือกเหนือ/ใต้จุดที่ชี้ตามพื้นที่จริง ติดตามการเลื่อนและ resize
- ลูกศรชี้กลับไปยังตำแหน่งจริง ไม่ใช่ภาพหน้าจอจำลอง
- หน้าต่างผลโอนใช้ native dialog จึงวาง tutorial ไว้ภายใน dialog และใช้ manual popover เพื่อแสดงเหนือชั้น modal โดยยังอยู่ในขอบเขตการโฟกัส
- Tab วนเฉพาะตัวควบคุมที่กำลังแนะนำและปุ่ม tutorial, Escape ใช้ข้าม และมีคำอธิบาย/ตัวเลขลำดับสำหรับ screen reader
- ถ้าหาจุดเป้าหมายไม่พบ มีข้อความพร้อมทางย้อนกลับ/ข้าม ไม่ให้ผู้ใช้ติดในหน้าว่าง

## การตรวจสอบ

Build และชุดทดสอบ UI 16 ข้อผ่าน รวมการวางกล่องบนจอแคบ จอ desktop และ viewport สั้น ตรวจลำดับจริงครบ 8 ขั้น การเปิดผลโอนใน native modal การกดปุ่มจริงและปุ่มถัดไป การย้อนกลับ การจบกลับหน้าแรก การไม่เปิดซ้ำหลังรีเฟรช และการเปิดใหม่จาก Hero ตรวจที่ความกว้าง 320, 390 และ 1440 พิกเซล รวมการข้ามด้วย Escape และคืนโฟกัสสู่หน้าผลโอน คอนโซลรอบสุดท้ายไม่มี error/warning ไม่มีการยืนยันโอนหรือย้ายเงินระหว่างการตรวจ

การตรวจนี้ยืนยันการทำงานของต้นแบบ ยังต้องให้ผู้ใช้ใหม่ลองโดยไม่ชี้ตำแหน่ง เพื่อประเมินความเข้าใจและการค้นพบฟีเจอร์จริง
